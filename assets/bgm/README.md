# 背景音乐目录

把 `.mp3` / `.wav` / `.m4a` / `.ogg` 音乐文件放进这个文件夹，合成视频时会**随机挑一首**自动混音（音量默认压到 12%，结尾 2 秒淡出）。

- 想固定用某一首：在 `config.json` 里填 `bgm.path`（相对项目根目录或绝对路径）
- 想关闭背景音乐：`config.json` 的 `bgm.enabled` 设为 `false`，或界面上取消勾选
- 调整音量：`bgm.volume`，0.05~0.2 之间比较合适（人声不会被盖住）

> 仓库里自带的 `sample_ambient.mp3` 是用 ffmpeg 合成的原创环境铺底音，可自由使用/删除。
> 请不要把有版权的商业音乐提交到公开仓库。
